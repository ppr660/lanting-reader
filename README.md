# 兰亭集序 · 山水长卷

《兰亭集序》动态绘本阅读与学习 Demo。页面、音频、插画和动态蒙版全部随站点提供，无需 API 密钥或后台服务。

## 体验

- 连续阅读，原画中的竹影、水流、衣袂和举杯局部动态。
- 云希朗读、背景琴音与环境声，支持速度和混音调节。
- 点词查义、句译、段落赏析和可开关的句读提示。
- 阅读完成后，进入生词巩固或句子、段落、全文拼接背诵；支持跳过层级。

## GitHub Pages 发布

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。根目录的 .nojekyll 保持静态文件直接发布。

## 本地预览

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 http://127.0.0.1:8766/ 。无需安装前端依赖。手机首次播放需点击播放按钮。学习记录保存在各自浏览器本地。

## 素材

插画来自用户指定的 [Wait 小红书笔记](https://www.xiaohongshu.com/discovery/item/6a73435c000000003301d359)，经过阅读裁切、去字和局部动画分层处理。朗读使用已生成的微软 Azure 云希音频。背景琴音和环境声为浏览器合成音效。
